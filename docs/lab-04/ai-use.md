# AI Use — Lab 4 (TokTickIT)

## LLM Used

ChatGPT (OpenAI) and an AI coding assistant were used throughout Lab 4 for understanding requirements, planning implementation, generating code across the database, backend and frontend tiers, debugging, automated testing and final verification.

My responsibility was to understand the system requirements and workflows, provide detailed implementation instructions, review the AI's results, and verify that the completed features matched the engineering contract.

## My Reflection

During Lab 4, I used AI primarily as an implementation assistant. My responsibility was to understand the requirements and workflows, identify how each feature should behave, and provide detailed instructions covering the database, backend API, frontend UI, and verification tests.

I learned that a specific prompt produced more useful results than a general request to implement a feature. For example, when implementing Actions Taken, I needed to explain its database relationships, lifecycle states, API authorization, Staff editing permissions, Requester read-only access, and expected test cases. This helped the AI implement the complete workflow across all three tiers.

I also learned to investigate test failures before changing code. During the combined regression run, three tests failed because the new Ticket Status History section made the Playwright Status locator ambiguous. The issue was resolved by targeting the correct dropdown, without changing the working application behavior.

AI performed much of the coding, debugging, and automated testing. I focused on understanding the workflow, defining the expected behavior, reviewing the results, identifying UI problems, and deciding whether the implementation met the Lab 4 requirements. This experience helped me improve my requirement analysis, system-level thinking, and ability to direct and evaluate AI-assisted software development.
