ChatGPT (OpenAI), used throughout Lab 3 for specification review, test
planning, implementation support, debugging, regression testing, and

## My Reflection

Working with an AI coding assistant was most effective when I provided specific Issues, acceptance criteria, tests and clear instructions about what code to preserve. This was especially important because authentication, roles, migrations and authorization affected multiple features at the same time.

The best practice was asking the AI to investigate failures before changing code. For example, during the migration regression, checking the test, migrations and current implementation showed that historical Tickets were missing the required IT Priority backfill. This prevented me from changing code that was already correct.

I still needed to verify everything myself. I ran the full regression and E2E suites, tested role and ownership behavior with different user accounts, and reviewed the visual evidence instead of assuming the implementation was correct just because one test passed.
